# cloudhouse
Cloudhouse is a modern, responsive agency website built with React.js, Vite, and Tailwind CSS, designed to showcase premium web development and Shopify services. This project reflects the core vision of Cloudhouse: empowering brands through clean, high-performance websites, seamless app integrations, and problem-solving Shopify expertise.

🔧 Tech Stack:
React.js – Component-based architecture for dynamic user interfaces

Vite – Blazing-fast development and optimized production builds

Tailwind CSS – Utility-first styling with custom theming

Framer Motion – Smooth, tasteful animations for a polished user experience

Poppins Font & Blue-Violet Theme – Modern aesthetic with brand consistency

🌟 Features:
Sleek, animated landing page with CTA sections

Service overview with visual hierarchy and hover interactions

Responsive layout for mobile, tablet, and desktop

Clean and scalable codebase for future expansion
